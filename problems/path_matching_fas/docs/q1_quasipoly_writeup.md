# Recognizing tournament degreewidth at most two in quasi-polynomial time

This note gives a self-contained proof skeleton for the current Q1 result:

> **Main theorem.** Given an `n`-vertex tournament `T`, whether
> `Δ*(T) ≤ 2` can be decided in deterministic time `n^{O(log n)}`.

The proof is deliberately phrased around reachable prefixes.  This is the
right abstraction for the algorithm: the recognizer is exact, and the only
question is how many reachable prefixes can occur.

## 1. Definitions

Let `T = (V,A)` be a tournament.  For `v ∈ V`, write

* `N^+(v) = {u : vu ∈ A}`,
* `N^-(v) = {u : uv ∈ A}`,
* `d^-(v) = |N^-(v)|`.

For a linear order `σ = (v_0, ..., v_{n-1})`, an arc `v_i v_j` is backward if
`j < i`.  The back-degree of a vertex in `σ` is the number of backward arcs
incident with it.  The degreewidth `Δ*(T)` is the minimum, over all linear
orders of `V`, of the maximum back-degree of a vertex.

A set `S ⊆ V` is a **reachable prefix** if the vertices of `S` can be ordered
as the first `|S|` positions of some order so that every vertex in `S` has
back-degree at most `2`, counting all vertices outside `S` as still unplaced
and therefore after the prefix.  Such an order of `S` is called a witnessing
prefix order.

For `p = |S|` and `u ∉ S`, define the placement back-degree

```text
bd(u | S) = |N^+(u) ∩ S| + |N^-(u) \ (S ∪ {u})|.
```

This is the final back-degree of `u` if `u` is appended after the prefix `S`;
future placements cannot change it.

## 2. The exact reachable-prefix recognizer

The following identity is the basic computational reformulation.

**Lemma 2.1 (placement identity).**  For `u ∉ S`, with `p = |S|`,

```text
bd(u | S) = 2|N^+(u) ∩ S| + d^-(u) - p.
```

**Proof.**  Since `T` is a tournament,

```text
p = |N^+(u) ∩ S| + |N^-(u) ∩ S|.
```

Also

```text
|N^-(u) \ (S ∪ {u})| = d^-(u) - |N^-(u) ∩ S|.
```

Substitution gives the formula. ∎

Thus reachable prefixes are generated by the recurrence

```text
∅ is reachable,
S ∪ {u} is reachable from S if bd(u | S) ≤ 2.
```

**Lemma 2.2 (exactness).**  The full set `V` is reachable if and only if
`Δ*(T) ≤ 2`.

**Proof.**  If `V` is reachable, its witnessing order has maximum back-degree
at most `2`, so `Δ*(T) ≤ 2`.  Conversely, any order witnessing `Δ*(T) ≤ 2`
has every initial segment reachable by the recurrence, because each appended
vertex has back-degree at most `2` at the moment it is placed. ∎

So the algorithm is immediate: enumerate all reachable prefixes by increasing
size and accept exactly when `V` is reached.  Its running time is
`O(n · R(T))`, up to the usual bitset arithmetic factors, where `R(T)` is the
number of reachable prefixes.  The rest of the proof bounds `R(T)`.

## 3. Window and budget lemmas

Fix a reachable prefix `S` of size `p`, with witnessing order
`v_0, ..., v_{p-1}`.  Positions are indexed from `0`.

### 3.1 Two-sided score window

**Lemma 3.1 (two-sided window).**  If `v_i ∈ S`, then

```text
|i - d^-(v_i)| ≤ 2.
```

In particular every vertex of `S` has `d^-(v) ≤ p+1`.

**Proof.**  Let

```text
b = |N^-(v_i) ∩ {v_0, ..., v_{i-1}}|.
```

The backward arcs incident with `v_i` consist of its out-neighbours before it
and its in-neighbours after it, hence

```text
bd(v_i) = (i - b) + (d^-(v_i) - b)
         = i + d^-(v_i) - 2b.
```

Since `b ≤ i` and `b ≤ d^-(v_i)`, this quantity is at least
`|i - d^-(v_i)|`.  The witnessing prefix has `bd(v_i) ≤ 2`, proving the
claim.  The upper bound `d^-(v_i) ≤ i+2 ≤ p+1` follows immediately. ∎

**Corollary 3.2 (upper-window occupancy).**  For every `k ≥ 0`,

```text
|S ∩ {v : d^-(v) ∈ [p-k, p+1]}| ≤ k+2.
```

**Proof.**  If `v_i ∈ S` and `d^-(v_i) ≥ p-k`, then Lemma 3.1 gives
`i ≥ d^-(v_i)-2 ≥ p-k-2`.  The possible positions are therefore among

```text
p-k-2, p-k-1, ..., p-1,
```

at most `k+2` positions. ∎

The special case `k=3` says

```text
|S ∩ {v : d^-(v) ∈ [p-3, p+1]}| ≤ 5,
```

and the slightly shifted band `[p-2,p+1]` contains at most `4` prefix
vertices.

### 3.2 Outside in-neighbour budget

**Lemma 3.3 (outside in-neighbour closure).**  For every `v ∈ S`,

```text
|N^-(v) \ S| ≤ 2.
```

Consequently the number of arcs from `V \ S` into `S` is at most `2p`.

**Proof.**  Every vertex of `V \ S` is after the prefix.  Thus every
in-neighbour of `v` outside `S` contributes a backward arc incident with `v`
in the witnessing prefix order.  Since `bd(v) ≤ 2`, there are at most two
such vertices.  Summing over `v ∈ S` gives at most `2p` arcs from `V \ S`
into `S`. ∎

**Lemma 3.4 (budget localization).**  Let `S` be a reachable prefix of size
`p`, and let `s < p`.  Then

```text
|{w ∉ S : d^-(w) ≤ s}| · (p-s) ≤ 2p.
```

**Proof.**  Let

```text
C = V \ S,
X = {w ∈ C : d^-(w) ≤ s}.
```

For `w ∈ X`, the out-degree of `w` is at least `n-1-s`.  At most `|C|-1`
out-neighbours of `w` lie in `C`, so

```text
|N^+(w) ∩ S| ≥ (n-1-s) - (|C|-1) = p-s.
```

Summing over `w ∈ X`, there are at least `|X|(p-s)` arcs from `X` into `S`.
But all such arcs are arcs from `V \ S` into `S`, and Lemma 3.3 bounds their
total number by `2p`. ∎

In particular, taking `s = floor(p/2)` gives

```text
|{w ∉ S : d^-(w) ≤ floor(p/2)}| ≤ 4.
```

## 4. Heredity under induced subtournaments

**Lemma 4.1 (hereditary reachable prefixes).**  Let `B ⊆ V`.  If `S` is a
reachable prefix of `T`, then `S ∩ B` is a reachable prefix of the induced
tournament `T[B]`.

**Proof.**  Take a witnessing prefix order of `S` and restrict it to
`S ∩ B`.  For a vertex `v ∈ S ∩ B`, its back-degree in the restricted order
inside `T[B]` is obtained from its original back-degree by deleting some
vertices before it and some vertices after it.  Both the out-before and
in-after contributions can only decrease.  Hence the restricted back-degree
is still at most `2`. ∎

This lemma is the recursion mechanism in the logarithmic diameter proof.

## 5. Diameter of reachable prefixes

For a tournament `T`, write `R_p(T)` for the family of reachable prefixes of
size `p`.  Define

```text
D(p) = max |S △ S'|,
```

where the maximum is over all tournaments `T` and all
`S,S' ∈ R_p(T)`.  Define the monotone envelope

```text
F(p) = max_{0 ≤ q ≤ p} D(q).
```

The envelope is needed because the recursive step passes to two reachable
prefixes of an induced tournament whose common size is at most, but not
necessarily equal to, the upper bound supplied by the window lemma.

### 5.1 Logarithmic diameter theorem

**Theorem 5.1.**  `F(p) = O(log p)`.  More explicitly, for `p ≥ 1`,

```text
F(p) ≤ 12 ceil(log_2 p) + 8.
```

**Proof.**  The cases `p ≤ 4` are covered by the trivial bound
`D(q) ≤ 2q`, hence `F(4) ≤ 8`.

Let `p ≥ 5`, and let `S,S'` be reachable prefixes of size `p` in the same
tournament.  Put

```text
s = floor(p/2),
L = {v : d^-(v) ≤ s},
W = {v : s+1 ≤ d^-(v) ≤ p+1}.
```

By Lemma 3.1, no vertex of either prefix has in-degree greater than `p+1`;
hence every vertex of `S △ S'` lies in `L ∪ W`.

First consider the low part `L`.  Every vertex of `(S △ S') ∩ L` is omitted
from one of `S` and `S'`.  Lemma 3.4, applied with threshold `s`, gives for
each prefix

```text
|{w ∉ S : d^-(w) ≤ s}| ≤ 2p/(p-s) ≤ 4,
```

and the same bound for `S'`.  Therefore

```text
|(S △ S') ∩ L| ≤ 8.                         (1)
```

The same budget bound also controls the size imbalance in the window.  Since
`|S| = |S'|`,

```text
||S ∩ W| - |S' ∩ W|| = ||S ∩ L| - |S' ∩ L||.
```

If, for example, `|S ∩ L| > |S' ∩ L|`, then at least
`|S ∩ L| - |S' ∩ L|` vertices of `L` are in `S` but omitted from `S'`; there
are at most `4` such vertices by Lemma 3.4 for `S'`.  Thus

```text
||S ∩ W| - |S' ∩ W|| ≤ 4.                   (2)
```

Next bound the absolute window sizes.  Since

```text
W = {v : d^-(v) ∈ [s+1,p+1]}
  = {v : d^-(v) ∈ [p-k,p+1]}
```

with `k = p-s-1 = ceil(p/2)-1`, Corollary 3.2 gives

```text
|S ∩ W|, |S' ∩ W| ≤ ceil(p/2)+1.             (3)
```

By Lemma 4.1, `S ∩ W` and `S' ∩ W` are reachable prefixes of the induced
tournament `T[W]`.  Suppose `|S ∩ W| ≥ |S' ∩ W|`, and set

```text
q = |S' ∩ W|.
```

By (2), the larger window prefix has at most four extra vertices.  Delete the
last `|S ∩ W|-q` vertices from a witnessing order of `S ∩ W` inside `T[W]`.
The remaining set `A` is still a reachable prefix of `T[W]`, has size `q`,
and differs from `S ∩ W` in at most four vertices.  Therefore

```text
|(S ∩ W) △ (S' ∩ W)|
   ≤ 4 + |A △ (S' ∩ W)|
   ≤ 4 + D(q)
   ≤ 4 + F(ceil(p/2)+1),                    (4)
```

where the last inequality uses (3) and the monotonicity of `F`.

Combining (1) and (4),

```text
|S △ S'| ≤ 12 + F(ceil(p/2)+1).
```

Taking the maximum over all tournaments and all same-size reachable pairs
gives

```text
D(p) ≤ 12 + F(ceil(p/2)+1).
```

Now take the maximum over all `q ≤ p`.  For `q ≤ 4`, `D(q) ≤ 8`.  For
`5 ≤ q ≤ p`, the function `ceil(q/2)+1` is non-decreasing, so

```text
D(q) ≤ 12 + F(ceil(q/2)+1)
     ≤ 12 + F(ceil(p/2)+1).
```

Hence, for `p ≥ 5`,

```text
F(p) ≤ 12 + F(ceil(p/2)+1).                 (5)
```

Since `ceil(p/2)+1 < p` for `p ≥ 5`, iterating (5) reaches the base range
`p ≤ 4` after `O(log p)` steps.  The displayed bound
`F(p) ≤ 12 ceil(log_2 p) + 8` is a convenient coarse unrolling. ∎

## 6. Counting reachable prefixes

**Lemma 6.1 (diameter-to-count).**  If `R_p(T)` is nonempty and has diameter
at most `r`, then

```text
|R_p(T)| ≤ Σ_{j ≤ floor(r/2)} C(p,j) C(n-p,j).
```

**Proof.**  Fix one reachable prefix `S_0 ∈ R_p(T)`.  Every other
`S ∈ R_p(T)` satisfies `|S △ S_0| ≤ r`.  Since `|S| = |S_0| = p`, the set
`S` is obtained from `S_0` by deleting `j` vertices and inserting `j`
vertices, where `2j = |S △ S_0| ≤ r`.  There are at most
`C(p,j)C(n-p,j)` choices for each `j`. ∎

**Theorem 6.2 (quasi-polynomial recognizer).**  The reachable-prefix
algorithm decides whether `Δ*(T) ≤ 2` in time `n^{O(log n)}`.

**Proof.**  By Theorem 5.1, the diameter of `R_p(T)` is at most
`O(log p)`, uniformly over all tournaments.  Lemma 6.1 gives

```text
|R_p(T)| ≤ Σ_{j ≤ O(log p)} C(p,j) C(n-p,j)
        ≤ n^{O(log n)}.
```

Summing over `p = 0, ..., n`, the total number of reachable prefixes is still
`n^{O(log n)}`.  The exact recognizer of Section 2 processes each reachable
prefix and tries at most `n` extensions, so it runs in quasi-polynomial time.
By Lemma 2.2 it accepts exactly the tournaments with `Δ*(T) ≤ 2`. ∎

## 7. Polynomiality and the constant-diameter target

The same counting argument shows the precise remaining target for this route.

**Proposition 7.1.**  If there is an absolute constant `c` such that
`D(p) ≤ c` for every `p`, then tournament `Δ*≤2` recognition is polynomial
time by the reachable-prefix recognizer.

**Proof.**  Lemma 6.1 gives

```text
|R_p(T)| ≤ Σ_{j ≤ c/2} C(p,j) C(n-p,j) = n^{O(c)}.
```

Summing over all `p` and trying all extensions preserves polynomial time. ∎

Thus the proved result is:

```text
D(p) = O(log p)     ⇒     Q1 ∈ n^{O(log n)}.
```

The polynomial-time version of this same proof strategy would require:

```text
D(p) = O(1)         ⇒     Q1 ∈ P.
```

Computational evidence in the project strongly suggests the stronger bound:
the observed same-size reachable-prefix diameter is at most `8` in the tested
families and does not grow with `n`.  The recursion above does not prove this.
Its additive `+12` per scale is real: the low-part contribution `8` and the
window-size truncation cost `4` do not telescope.  A proof of polynomial time
therefore needs a non-recursive absolute exchange argument, not merely a
sharpening of the halving induction.

## 8. Relation to known literature

Degreewidth for tournaments was introduced by Davot, Isenmann, Roy and
Thiebaut in *Degreewidth: a New Parameter for Solving Problems on
Tournaments*, arXiv:2212.06007; the WG 2023 version appears in LNCS 14093.
Their abstract states that sparse tournaments are exactly the tournaments of
degreewidth one, that sparse tournaments can be recognized in cubic time, and
that computing tournament degreewidth is NP-hard.

For oriented graphs, Aboulker, Oijid, Petit, Rocton and Simon prove in
*Computing the degreewidth of a digraph is hard*, arXiv:2407.19270, that for
every integer `k ≥ 1`, `k`-Degreewidth is NP-complete.  The DMTCS version was
published in volume 28:2 on April 9, 2026.  This does not settle the tournament
case `Δ*≤2`.  The theorem above places that case in quasi-polynomial time.

Reference URLs:

* Davot, Isenmann, Roy, Thiebaut: https://arxiv.org/abs/2212.06007
* Aboulker, Oijid, Petit, Rocton, Simon: https://arxiv.org/abs/2407.19270
* DMTCS version: https://dmtcs.episciences.org/17969
